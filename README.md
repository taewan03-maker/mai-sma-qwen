# MAI SMA · Qwen3-1.7B

선박 정비 기록을 검색하고 근거 원문과 함께 답하는 웹페이지입니다. 별도 설치나 유료 API 없이 WebGPU 지원 PC의 최신 Chrome·Edge에서 사용합니다.

## 사용 방법

1. 공개 웹페이지에 접속합니다.
2. **Qwen 모델 불러오기**를 누릅니다. 처음에는 모델 약 1GB와 실행 환경을 다운로드하므로 시간이 걸립니다. 브라우저에 모델이 캐시됩니다.
3. 준비 완료 후 “발전기 배기가스 온도가 높아 어떻게 해야 해?”처럼 질문합니다.
4. 출처 버튼을 눌러 근거 기록을 확인합니다. 선박별 건수·부품 소모 등 집계 질문은 모델 없이도 사용할 수 있습니다.

모델 실행에는 약 2–3GB 이상의 사용 가능한 GPU 메모리와 추가 여유 메모리가 필요합니다. WebGPU 미지원 환경에서는 모델을 실행할 수 없습니다. 휴대전화에서는 실행을 보장하지 않습니다.

## 데이터와 답변

- 사용자가 공개를 요청한 MAI_SMA 학생 전달 DB를 포함합니다. 이 저장소의 데이터 파일은 누구나 다운로드할 수 있습니다.
- 정비 문서 1,000건, PMS 작업 2,296행, 결재 2,979행, 첨부 286행, 부품 소모 174행, 선박 6척입니다.
- 본문이 있는 정비 문서 741건과 중복 제거 절차 참고 기록 305건으로 검색 색인 1,046건을 구성했습니다. 참고 기록은 문서 건수 집계에 포함하지 않습니다.
- BM25 검색 후 Qwen3-1.7B가 검색 근거를 바탕으로 답변합니다. 추가 학습으로 모델 가중치를 변경한 방식이 아닌 RAG입니다.
- 인용문은 원문에서 복사하고 일치 여부를 검사합니다. **인용 일치는 한국어 해석의 정확성이나 현재 설비에 대한 진단을 보장하지 않습니다.**
- 과거 정비 사례를 보여줍니다. 실제 조치는 제조사 매뉴얼·선내 절차와 담당 기관사의 판단을 따르세요. 비용 컬럼이 없으며, 작업 시간은 기본값 비중이 높아 신뢰할 수 있는 집계를 제공하지 않습니다.
- 통계는 고정된 읽기 전용 SQL로 계산합니다. 문서 조인은 VESSELCODE와 DOC_NO를 함께 사용합니다.

## 실행 구조

GitHub Pages에서 HTML·CSS·JavaScript와 데이터 파일을 제공합니다. Qwen3-1.7B는 WebLLM으로 방문자의 브라우저에서 실행됩니다. 질문을 외부 추론 API로 전송하지 않습니다. 실행 환경은 CDN, 모델 파일은 Hugging Face에서 다운로드하므로 최초 접속에는 인터넷이 필요합니다. 대화는 현재 브라우저의 localStorage에 저장됩니다.

사용 구성 요소: [WebLLM](https://github.com/mlc-ai/web-llm), [Qwen3-1.7B](https://huggingface.co/Qwen/Qwen3-1.7B), [MLC 변환 모델](https://huggingface.co/mlc-ai/Qwen3-1.7B-q4f16_1-MLC), [SQL.js](https://github.com/sql-js/sql.js). 각 구성 요소의 이용 조건은 해당 출처를 확인하세요.

## GitHub Pages 설정

Settings → Pages → Deploy from a branch → main → /(root) → Save.

로컬 미리보기는 이 폴더에서 `python -m http.server 8790` 실행 후 `http://localhost:8790`에서 확인할 수 있습니다. 파일을 더블클릭한 file:// 접속은 지원하지 않습니다.
